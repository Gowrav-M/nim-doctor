# Changelog

## 0.1.0

- Initial local-first NVIDIA NIM diagnostic CLI.
- Added offline demo, doctor, discover, test, check, init, and report commands.
- Added config templates for Cursor, Continue, LiteLLM, CrewAI, LlamaIndex, and OpenCode.
- Added JSON, Markdown, and HTML evidence reports.
- Added `compat` command for NIM agent-readiness matrices covering chat, streaming, tool calls, streaming tool calls, and JSON mode.
- Added strict schemas, tests, and GitHub Actions.
